# Vela CRM

Открытая CRM для малого и среднего бизнеса: сделки, задачи, проекты, финансы, команда и обмен данными с 1С.
Работает на вашем сервере, данные остаются у вас.

**Демо:** https://babajusik.github.io/vela-crm/ — вход в один клик под любым сотрудником (пароль `demo1234`).
В демо вся CRM работает прямо в браузере: каждый посетитель получает свою копию данных, никто никому не мешает.

## Обмен с 1С

Три способа, можно сочетать:

1. **OData (прямое подключение).** CRM сама ходит в опубликованную базу 1С:Бухгалтерии 3.0, УТ 11 или УНФ:
   забирает контрагентов, номенклатуру и поступления оплат, выгружает новых клиентов и выставленные счета.
   Клиенты сопоставляются по ИНН, товары — по артикулу, дублей нет. Обмен вручную или по расписанию.
2. **CommerceML 2 («Обмен с сайтом»).** Стандартный механизм УТ, УНФ, КА и ERP: в 1С указываете адрес
   `https://ваш-сервер/api/1c/exchange` — 1С сама выгружает каталог, цены и остатки и забирает заказы.
3. **REST API.** Для доработанных конфигураций: пример кода на встроенном языке 1С — в настройках интеграции.

Подробная инструкция для каждого способа — в разделе «Настройки → Интеграция с 1С».

## Установка на свой сервер

Нужен Linux-сервер с Docker (2 ядра, 4 ГБ памяти достаточно для 50 пользователей).

```bash
git clone https://github.com/Babajusik/vela-crm.git
cd vela-crm
# задайте название компании, email и пароль администратора в docker-compose.yml
docker compose up -d
```

CRM откроется на порту 3000. Поставьте перед ней Nginx или Caddy с HTTPS-сертификатом.

Без Docker: Node.js 22.13 или новее.

```bash
npm ci
npm run build
ADMIN_EMAIL=admin@company.ru ADMIN_PASSWORD=секрет npm start
```

### Переменные окружения

| Переменная | Значение |
| --- | --- |
| `PORT` | порт, по умолчанию 3000 |
| `DATA_DIR` | папка с базой и файлами, по умолчанию `./data` |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME`, `COMPANY_NAME` | первый администратор (создаётся один раз) |
| `DEMO=1` | заполнить базу демо-данными |

### Резервные копии

Все данные лежат в `data/vela.db` (SQLite) и `data/files/`. Копируйте их каждую ночь, например:

```bash
sqlite3 data/vela.db ".backup '/backup/vela-$(date +%F).db'" && rsync -a data/files/ /backup/files/
```

Плюс в интерфейсе: «Настройки → Резервная копия».

## Разработка

```bash
npm install
npm run dev          # интерфейс + ядро в браузере (как демо), http://localhost:5173
npm run dev:server   # сервер API на :3000; интерфейс с ним: VITE_ENGINE=http npm run dev
npm test             # тесты ядра: сделки, счета, финансы, выписки, 1С, бизнес-процессы, права
npm run build:demo   # статическая демо-версия для GitHub Pages
```

Устройство: ядро (`src/core`) — схема данных, бизнес-логика, маршруты API и обмен с 1С. Одно и то же ядро
работает на сервере (Node.js + SQLite) и в браузере (SQLite в WebAssembly) — поэтому демо полностью рабочее.
Интерфейс — React, TypeScript, Tailwind CSS.
